# Darshan Ramani — Advanced Static Portfolio

A framework-free portfolio built with:

- HTML
- CSS
- Vanilla JavaScript

## Files

- `index.html`
- `style.css`
- `script.js`

## Run locally

Double-click `index.html`, or open the folder with VS Code + Live Server.

## GitHub Pages deployment

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Deploy from your main branch / root folder.
5. GitHub will generate the public URL.

No npm, React, Node.js, build step, or package installation is required.
